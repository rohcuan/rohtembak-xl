Cara Mendapatkan Chat ID & API Key

    
    
        
  1. Buka Telegram, cari @BotFather, kirim /newbot dan ikuti petunjuknya sampai Anda menerima token API (formatnya seperti 1234567890:AAE...). Itu yang diisi di kolom API Key Bot.
    2. 
        
  2. Kirim satu pesan apa saja (misal halo) ke bot yang barusan Anda buat — bot tidak bisa mengirim pesan duluan ke Anda sebelum pernah di-chat.
    3. 
        
  3. Ambil Chat ID Anda lewat bot @userinfobot: buka chat-nya dan dia langsung membalas ID Anda (angka panjang, mis. 123456789). Isi angka itu di kolom Chat ID.
    4. 
        
  4. Klik Simpan Pengaturan, lalu uji dengan tombol Backup Sekarang. Kalau file zip muncul di chat Telegram Anda, setup selesai.
    5. 
    

    
Catatan: batas ukuran kirim via Bot API adalah 50 MB per file. Backup berisi data sensitif — jangan sebarkan token bot & chat ID.
